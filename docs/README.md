# Dokumentation

Dieser Ordner enthält die Prozessdokumentation, das Kochbuch zur Implementierung des Standards sowie Materialien für die Arbeitsgruppe. Die Inhalte werden im Verlauf der Projektphasen befüllt und gepflegt. Technische und narrative Formate werden parallel geführt, um sowohl Entwicklerinnen als auch Verbandsvertreterinnen anzusprechen.
