# Schema

Dieser Ordner enthält das Kerndatenschema (`organisation.json`) und die zugehörige Dokumentation. Das Schema definiert alle Felder für Organisationsprofile: Grunddaten, Rechtsform, Tätigkeitsbereiche und statistische Kennzahlen. Aktueller Stand: Version 0.1 — Diskussionsentwurf. Noch nicht stabil, Änderungen sind ausdrücklich vorgesehen.
